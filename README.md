# faronFlux

Android-клиент для туннелей на базе [OpenFluxAndroid](https://github.com/p1neappleXpress/OpenFluxAndroid).

> **faronFlux** — это форк [OpenFluxAndroid](https://github.com/p1neappleXpress/OpenFluxAndroid). Оригинальный проект: https://github.com/p1neappleXpress/OpenFluxAndroid

## Описание

VPN/туннель-клиент: поднимает локальный transport (встроенный native-процесс), запускает `tun2socks` и проксирует трафик выбранного туннеля. Поддерживает добавление конфигураций по QR-коду и вручную.

## Основные изменения относительно оригинала

- **Полный редизайн интерфейса**: тёмная тема, hero-карточка со статусом и аптаймом, нижняя навигация «Туннели / Настройки», формы на базе Material.
- **Material You**: на Android 12+ акценты берутся из динамической палитры обоев; на старых версиях — собственный тёмный акцент.
- **Экран настроек**: автоподключение при запуске, автозапуск при загрузке устройства, логи, раздел «О приложении».
- **Логи**: полноэкранная страница с автоскроллом и подсветкой; скрытый вход по долгому нажатию на заголовок «faronFlux».
- **Последовательность старта/остановки**: при переключении туннеля текущий корректно останавливается до запуска нового.
- **Иконка**: собственная адаптивная иконка (молния в щите) + монохромная версия для тематических иконок Android 13.
- **Пакет**: `dev.faron.flux` (отличается от оригинального пакета).
- Обновлены зависимости: `compileSdk 36`, Material 1.13, `quickie-bundled 1.12` (ML Kit сканирование QR с выравниванием 16K страниц).
